# Ajuste renal de antimicrobianos

Formulario docente que calcula el aclaramiento de creatinina, cruza cada fármaco con la tabla de ajustes y registra el resultado en Google Sheets mediante Make.

**Solo datos sintéticos. No ingresar pacientes reales.**

## Variable de Railway

| Variable | Valor |
|---|---|
| `MAKE_WEBHOOK_URL` | URL del webhook del escenario de Make |

## Pruebas

```
npm install
npm test
```
